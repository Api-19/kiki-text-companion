# 文本聊天安装说明

## 1. 这是什么

这是在你自己的电脑上运行的文本聊天工具。它只模仿你发出的消息；对方的消息只用于理解上下文，不作为被模仿的样本。它不提供语音、声音克隆，也不能保证已经像你本人。

原始聊天和生成的数据存在本机。聊天时，所需聊天片段会发给你选的云端模型服务；系统只自动处理部分固定格式信息，**人名、地名、学校、单位不会被替换，会原样发送**。两个人都应了解并同意后再使用。

**Windows 版本未在真实 Windows 电脑上验证。**

## 2. 准备

1. 从 [Python 官方网站](https://www.python.org/downloads/) 下载 **Python 3.12** 官方安装包并安装，不要用其他版本代替。Mac 选择 macOS 安装包；Windows 选择 Windows 安装包，并勾选 **Add python.exe to PATH**。安装后关闭旧窗口。项目里已有可用的 .venv 时，启动器直接使用它。
2. 准备一个云端模型服务的 API key。默认服务是 DeepSeek，设置时服务地址和模型名直接按回车即可；也可填写其他 OpenAI 兼容服务的地址、模型名和对应 API key。不要把 key 发给别人。
3. 将收到的整个项目解压到本机普通文件夹后双击运行；不支持放在网络共享路径（`\\` 开头）中运行，也不支持把输出重定向到文件或管道。不要只拿走四个启动脚本；之后也不要移动项目位置，否则需要重新设置。打开项目里的 `scripts` → `share` 文件夹，Mac 使用 `.command` 文件，Windows 使用 `.bat` 文件。首次安装需要网络。

## 3. 准备 iPhone 聊天备份

用数据线连接 iPhone 并信任这台电脑。在 Mac 的 Finder 中选中 iPhone；Windows 使用 Apple Devices 或 iTunes。选择将 iPhone 备份到**这台电脑**，**不要勾选“加密本地备份”**，然后执行备份并等待完成。此前已加密的备份需要关闭加密后重新备份。

备份包含整台手机的数据，请妥善保管；设置完成且不再需要后可以删除。删除备份不会自动删除本工具已导出的聊天数据。第三方读取微信数据可能违反微信用户协议，需自行判断是否使用。这里只选择一段双方同意的私聊，不使用群聊。

## 4. 双击“开始设置”

打开 `scripts/share`，双击对应系统的“开始设置”。Mac 如果被系统阻止，可右键文件选择“打开”，按系统提示确认。

脚本会在项目里创建 `.venv` 环境并安装依赖。随后请按窗口提示操作：

1. 两个人分别阅读同意说明，并各自输入 **同意**。
2. 分别为被模仿的人和陪聊的人输入 **他** 或 **她**；直接回车分别默认为“他”和“她”。
3. 按编号选择 iPhone 备份、微信账号和聊天对象。只有一个备份或账号时会自动选中。
4. 填写模型服务地址、模型名；默认 DeepSeek 可直接回车。
5. 粘贴 API key 并回车。输入时不显示字符是正常现象。

最后应看到 **“自动检查通过；是否像本人未经人工验证”**。这只表示免费离线检查通过，没有调用云端模型，也没有证明模仿质量。若同时显示“样本结论：证据不足”，需要更多有效聊天样本。按回车（Windows 按任意键）关闭窗口。

## 5. 双击“开始聊天”

双击同一文件夹里的“开始聊天”。看到输入提示后，输入文字并回车发送。输入 `/exit` 并回车退出；再按提示关闭窗口。聊天需要联网，可能产生模型费用。

同一时间只能开一个聊天窗口。再次打开时会提示“已经有一个聊天窗口在运行，请先关闭它。”；请先退出原来的聊天窗口，再重新打开。

设置和聊天也不能同时进行。设置前请先退出聊天；看到“聊天窗口还开着，请先关闭再设置。”时，关闭聊天后重试。设置期间请等待设置结束，再打开聊天窗口。

开始聊天要求已有的 `private`、`private/dialogue` 以及实际片段库、习惯卡和隐语词表的来源父目录安全；缺失或不安全时会拒绝启动，不会创建缺失目录或自动修改权限。Mac 等 POSIX 系统要求这些目录属于当前用户，权限精确为 `0700`；Windows 沿用目录和链接检查，不检查 ACL。

## 6. 常见问题

- **没有找到 Python 3.12**：重新安装 Python 3.12 官方安装包。Windows 确认勾选 Add python.exe to PATH，关闭窗口后重试；Mac 使用官方 macOS 安装包。只装其他版本不行。
- **找不到备份**：确认备份到的是这台电脑而非 iCloud，且已备份完成。使用当前电脑账号运行脚本。Mac 上还需在“系统设置”→“隐私与安全性”→“完全磁盘访问权限”中打开“终端”，然后关闭终端窗口重新双击。如果备份在自选目录，可在重新设置命令后追加 `--backup "备份文件夹路径"`，引号里替换为自己的备份目录。
- **备份已加密**：在 Finder、Apple Devices 或 iTunes 中关闭“加密本地备份”，重新备份，再设置。
- **样本证据不足**：选择有更多本人发出消息的私聊。目标至少 30 条有效本人回复样本；过滤后数量可能比聊天软件里少。增加有效记录后重新设置，离线检查不能代替本人判断。
- **环境损坏时**：窗口显示“项目里的 .venv 环境不可用（可能是从别的电脑拷贝过来的）……”时，删除项目文件夹里的 `.venv` 文件夹，再重新运行“开始设置”。聊天数据和设置不在 `.venv` 里，不会丢失。
- **安装依赖失败，请检查网络后重试**：检查网络，重新双击“开始设置”。
- **文本聊天暂时无法启动**：确认在同一个电脑账号下完成了设置，且最后看到自动检查通过；确认项目未被移动、`kiki-share` 数据未被删除，并检查钥匙串或凭据管理器中的 key 是否仍在。已有私有目录不安全也会拒绝启动，程序不会自动修权限；遇到目录权限问题请保留数据并求助。可用下面的 `--rebuild` 重新设置，核对模型服务地址、模型名和 API key。若仍失败，保留窗口提示求助；不要发送原始聊天或 API key。

### 如何重新设置

重新设置会重新生成本工具的配置和样本，请先确认选对了聊天对象。Mac 打开“终端”，输入下面的命令；把引号里的路径替换成你实际解压的项目路径：

```bash
"项目路径/scripts/share/开始设置.command" --rebuild
```

Windows 打开“命令提示符”（cmd），输入：

```bat
"项目路径\scripts\share\开始设置.bat" --rebuild
```

两人仍需分别确认同意。重建时会沿用上次设置的双方人称；如需修改，可追加 `--owner-pronoun 她` 或 `--partner-pronoun 他`（均可选“他”或“她”）。重建时同时提供 `--owner-pronoun` 和 `--partner-pronoun` 会直接使用指定人称，不读取旧配置的人称，因此旧配置损坏时也可用原重建命令恢复；只提供一个参数仍需读取旧配置。请按双方实际人称填写，无需删除整个数据目录。API key 按服务地址分别保存在本机钥匙串或凭据管理器中；设置和聊天使用相同的地址校验与规范化：去掉首尾空白、统一协议和主机名大小写、省略默认端口（如 HTTPS 的 `:443`）、编码中文路径，再去掉路径末尾的 `/`；路径和查询参数仍区分大小写。例如 `/teamA/v1` 和 `/teama/v1` 分别保存 key。换服务地址时，`--rebuild` 需要重新粘贴该服务的 key；只有该地址已保存过 key 时，直接回车才能保留，输入新 key 则替换该地址的凭据。聊天只使用当前地址保存的 key，环境变量中的 key 不会覆盖它。旧版仅按变量名保存的 key，或曾按含默认端口、未编码中文的地址保存的 key，需要通过 `--rebuild` 重新粘贴。

已填写的用户词表、删除记录和用量账本会保留；词表损坏时会在“用户词表”步骤停止，需要修正词表后重试。分享模式只支持按时间段删除。设置或重建时，如果删除记录中含有按片段 ID 记录的条目，会在“片段库”步骤停止并提示条数，不生成可启动的配置；请改为按时间段记录后再重新设置。按时间段记录的删除照常生效。首次设置失败且尚未生成运行配置时，可直接重新运行原命令，无需手动删除中间文件。

重建默认会重新生成习惯卡。如果手工换过习惯卡（`private/style/snippets/habit_card.txt`）想保留，在上面的命令后追加 `--keep-habit-card`，例如 `--rebuild --keep-habit-card`；习惯卡不会被读取、检查或改写，窗口显示“习惯卡：保留现有（未重新生成）”。找不到现有习惯卡时，设置会在“本机目录”步骤停止并提示去掉 `--keep-habit-card` 重新设置，原有设置不受影响，仍可照常聊天。

iPhone 备份、JSONL（`--format jsonl --chat "文件路径"`）和 Standard JSON v1 数组（`--format standard --chat "文件路径"`）三种输入都支持 `--through-date YYYY-MM-DD`。截止日包含指定时区下当天整天及此前全部消息，次日 00:00:00 起的消息排除；先按消息日期筛选，再执行现有配对规则建库，不会把截止日前的话题配上截止日后的被模仿者回复。`--timezone` 默认 `Asia/Shanghai`；省略 `--through-date` 时，默认日期取本次参数解析时指定时区的当天，不读取操作系统时区。例如可在设置或重建命令后追加 `--through-date 2026-07-17 --timezone America/New_York`。

从 iPhone 备份或 JSONL 设置时，会先为全部消息按秒重新编号，保留每一条消息。同一秒内的先后顺序以输入 JSONL 的行序为准，不读取 `local_id` 字段：iPhone 导出文件已按消息时间和本地自增 ID（MesLocalID）排序，直接 JSONL 则使用文件原有行序。预处理将 `server_id` 改为 `timestamp * 1000 + k`，其中 `k` 是同一秒内从 0 开始的行序位置；同一秒超过 1000 条时设置失败，不显示聊天内容。窗口显示“同秒含图片等消息的时刻：N 处（已按原顺序保留）”，只报告含多条消息且有非文字消息的秒数。随后按保留下来的媒体边界筛选回复样本；“文字 → 图片 → 依赖图片的回复”不会进入片段库，同秒纯文字配对仍按原顺序保留。原始输入文件不变，预处理结果保存在本机数据目录的 `private/share/prepared.jsonl`；失败后重试会重新生成。`--format standard` 不经过这次 JSONL 预处理，也不重新编号消息；先校验完整原始输入，再按截止日期筛选，然后建库。每条消息的 `timestamp` 必须是带时区的 ISO 8601 字符串；缺失、空值、数字、无时区或其他非法时间都会使整次设置在“聊天转换”步骤失败，即使该消息原本会被日期筛选排除。原始 standard 输入保持不变；每次设置或重建都会重新生成本机 `private/share/filtered-standard.json`，仅写入保留消息（包括非文字标记），POSIX 文件权限为 `0600`。筛选结果为空也会在“聊天转换”步骤停止，不询问或保存 API key，不生成运行配置。日期筛选只约束建库输入，不表示磁盘上的原始导出或 JSONL 预处理文件已经按日期裁剪。

### 如何删除全部数据

先退出聊天，然后删除本工具的数据文件夹：

- Mac：在 Finder 的“前往”→“前往文件夹”中输入 `~/Library/Application Support/kiki-share`，删除整个 `kiki-share` 文件夹。
- Windows：在文件资源管理器地址栏输入 `%LOCALAPPDATA%\kiki-share`，删除整个 `kiki-share` 文件夹。

再在 Mac“钥匙串访问”中查找并删除服务名为 `kiki-companion` 的条目；Windows 在“凭据管理器”的“Windows 凭据”中删除名称为 `kiki-companion` 的条目，以及所有名称以 `@kiki-companion` 结尾的条目（更换过服务地址时可能有多条）。若要清理备份，用 Finder、Apple Devices 或 iTunes 管理并删除 iPhone 本地备份；你另存的聊天文件也需自行删除。最后可删除整个项目文件夹（包含 `.venv`）。本机删除不会撤回已发送到云端模型服务的数据。

### 费用

设置阶段只做免费离线检查。聊天阶段可能产生云端模型费用；程序的默认月上限是 **100 元**，按偏高单价估算（每百万输入 token 4 元、输出 token 16 元）。这是程序本地预算估算，不是服务商账单承诺；其他模型的实际价格可能不同，请同时查看服务商余额和用量，并在服务商侧设置费用限制。
