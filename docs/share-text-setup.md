# 文本聊天安装说明

## 1. 这是什么

这是在你自己的电脑上运行的文本聊天工具。它模仿你选定的一方。另一方的消息只用作上下文。它不提供语音、声音克隆，也不能保证已经像你本人。

原始聊天和生成的数据存在本机。聊天时，所需聊天片段会发给你选的云端模型服务；系统只自动处理部分固定格式信息，**人名、地名、学校、单位不会被替换，会原样发送**。两个人都应了解并同意后再使用。

**Windows 版本未在真实 Windows 电脑上验证。**

## 2. 准备

1. 从 [Python 官方网站](https://www.python.org/downloads/) 下载 **Python 3.12** 官方安装包并安装，不要用其他版本代替。Mac 选择 macOS 安装包；Windows 选择 Windows 安装包，并勾选 **Add python.exe to PATH**。安装后关闭旧窗口。项目里已有可用的 .venv 时，启动器直接使用它。
2. 准备一个云端模型服务的 API key。默认服务是 DeepSeek，设置时服务地址和模型名直接按回车即可；也可填写其他 OpenAI 兼容服务的地址、模型名和对应 API key。不要把 key 发给别人。
3. 将收到的整个项目解压到本机普通文件夹后双击运行；不支持放在网络共享路径（`\\` 开头）中运行，也不支持把输出重定向到文件或管道。不要只拿走四个启动脚本；之后也不要移动项目位置，否则需要重新设置。打开项目里的 `scripts` → `share` 文件夹，Mac 使用 `.command` 文件，Windows 使用 `.bat` 文件。首次安装需要网络。

## 3. 准备 iPhone 聊天备份

用数据线连接 iPhone 并信任这台电脑。在 Mac 的 Finder 中选中 iPhone；Windows 使用 Apple Devices 或 iTunes。选择将 iPhone 备份到**这台电脑**，**不要勾选“加密本地备份”**，然后执行备份并等待完成。此前已加密的备份需要关闭加密后重新备份。

备份包含整台手机的数据，请妥善保管；设置完成且不再需要后可以删除。删除备份不会自动删除本工具已导出的聊天数据。第三方读取微信数据可能违反微信用户协议，需自行判断是否使用。这里只选择一段双方同意的私聊，不使用群聊。

## 4. 双击“开始设置”

打开 `scripts/share`，双击对应系统的“开始设置”。Mac 如果被系统阻止，可右键文件选择“打开”，按系统提示确认。

脚本会在项目里创建 `.venv` 环境并安装依赖。随后请按窗口提示操作：

1. 选择导入方式，两个人分别确认同意。iPhone 备份可按编号选择备份、微信账号和一段私聊；只有一个备份或账号时会自动选中。文件方式支持 JSONL 和 Standard JSON v1，输入完整文件路径即可。
2. 导入校验后，选择模仿原账号（发送方）或聊天对方（接收方）。核对显示的会话、日期范围和角色，双方同意后输入「同意」。先填被模仿者的人称，再填陪聊者的人称。所选一方的回复用于建库。
3. 填写模型服务地址、模型名和自己的 API Key。服务和模型可直接回车使用默认配置。输入 Key 时不显示字符。
4. 程序在本机配对、过滤并生成习惯卡。若提示「样本结论：证据不足」，说明有效回复较少。离线检查通过仍需人工判断模仿效果。
5. 输入「开始」允许模型分析并出题，可能计费。它会收到已保留片段的回复长度、连发条数、追问等候选信号及长短分类。原文、人名、具体梗和事实只在本机页面对照。直接回车可跳过，设置仍可用于聊天。
6. 出题后会尝试打开本机网页，题目直接显示。如果浏览器没有打开，复制终端显示的临时地址。结束网页后会回到同一个终端聊天会话，「仅本次」保存的事实可在该会话使用。

遇到模型失败、预算不足或找不到候选时，可继续使用已保存的设置。按对应提示核对 Key、服务地址、模型、网络或预算，稍后从正常聊天重新校准。以后可双击「开始聊天」。

## 5. 双击“开始聊天”

双击同一文件夹里的“开始聊天”。看到输入提示后，输入文字并回车发送。输入 `/exit` 并回车退出；再按提示关闭窗口。聊天需要联网，可能产生模型费用。

同一时间只能开一个聊天窗口。再次打开时会提示“已经有一个聊天窗口在运行，请先关闭它。”；请先退出原来的聊天窗口，再重新打开。

设置和聊天也不能同时进行。设置前请先退出聊天；看到“聊天窗口还开着，请先关闭再设置。”时，关闭聊天后重试。设置期间请等待设置结束，再打开聊天窗口。

开始聊天要求已有的 `private`、`private/dialogue` 以及实际片段库、习惯卡和隐语词表的来源父目录安全；缺失或不安全时会拒绝启动，不会创建缺失目录或自动修改权限。Mac 等 POSIX 系统要求这些目录属于当前用户，权限精确为 `0700`；Windows 沿用目录和链接检查，不检查 ACL。

## 6. 常见问题

- **没有找到 Python 3.12**：重新安装 Python 3.12 官方安装包。Windows 确认勾选 Add python.exe to PATH，关闭窗口后重试；Mac 使用官方 macOS 安装包。只装其他版本不行。
- **找不到备份**：确认备份到的是这台电脑而非 iCloud，且已备份完成。使用当前电脑账号运行脚本。Mac 上还需在“系统设置”→“隐私与安全性”→“完全磁盘访问权限”中打开“终端”，然后关闭终端窗口重新双击。如果备份在自选目录，可在重新设置命令后追加 `--backup "备份文件夹路径"`，引号里替换为自己的备份目录。
- **备份格式不兼容或存在 SQLite WAL**。请检查备份是否完整并重新生成非加密备份，也可导入 JSONL 或 Standard JSON。程序不会修改原备份。
- **备份已加密**：在 Finder、Apple Devices 或 iTunes 中关闭“加密本地备份”，重新备份，再设置。
- **样本证据不足**：选择有更多本人发出消息的私聊。目标至少 30 条有效本人回复样本；过滤后数量可能比聊天软件里少。增加有效记录后重新设置，离线检查不能代替本人判断。
- **环境损坏时**：窗口显示“项目里的 .venv 环境不可用（可能是从别的电脑拷贝过来的）……”时，删除项目文件夹里的 `.venv` 文件夹，再重新运行“开始设置”。聊天数据和设置不在 `.venv` 里，不会丢失。
- **安装依赖失败，请检查网络后重试**：检查网络，重新双击“开始设置”。
- **文本聊天暂时无法启动**：确认在同一个电脑账号下完成了设置，且最后看到自动检查通过；确认项目未被移动、`kiki-share` 数据未被删除，并检查钥匙串或凭据管理器中的 key 是否仍在。已有私有目录不安全也会拒绝启动，程序不会自动修权限；遇到目录权限问题请保留数据并求助。可用下面的 `--rebuild` 重新设置，核对模型服务地址、模型名和 API key。若仍失败，保留窗口提示求助；不要发送原始聊天或 API key。

### 如何重新设置

重新设置会重新生成本工具的配置和样本，请先确认选对了聊天对象。Mac 打开“终端”，输入下面的命令；把引号里的路径替换成你实际解压的项目路径：

```bash
"项目路径/scripts/share/开始设置.command" --rebuild
```

Windows 打开“命令提示符”（cmd），输入：

```bat
"项目路径\scripts\share\开始设置.bat" --rebuild
```

两人仍需分别确认同意。引导重建可沿用上次的模拟方向，也可明确选择另一方。相同目标沿用双方人称和校准。文件版按导入内容和角色核对目标，已绑定文件只移动位置可沿用。内容更新、导入范围变化或旧版本绑定无法确认时，会提示需要重新校准，可取消并继续使用旧设置。如需指定人称，可追加 `--owner-pronoun 她` 或 `--partner-pronoun 他`（均可选“他”或“她”）。重建时同时提供 `--owner-pronoun` 和 `--partner-pronoun` 会直接使用指定人称，不读取旧配置的人称，因此旧配置损坏时也可用原重建命令恢复；只提供一个参数仍需读取旧配置。请按双方实际人称填写，无需删除整个数据目录。API key 按服务地址分别保存在本机钥匙串或凭据管理器中；设置和聊天使用相同的地址校验与规范化：去掉首尾空白、统一协议和主机名大小写、省略默认端口（如 HTTPS 的 `:443`）、编码中文路径，再去掉路径末尾的 `/`；路径和查询参数仍区分大小写。例如 `/teamA/v1` 和 `/teama/v1` 分别保存 key。重建时模型服务地址和模型名默认沿用当前配置。回车保留当前配置引用的 Key，换地址时按提示填写对应 Key。重建提供的新 Key 先保存在独立条目，校验通过并发布新配置后才生效。可恢复的失败保留旧配置引用的 Key。聊天使用当前配置引用的本机凭据。旧版仅按变量名保存的 key，或曾按含默认端口、未编码中文的地址保存的 key，需要通过 `--rebuild` 重新粘贴。

已填写的用户词表、删除记录和用量账本会保留；词表损坏时会在“用户词表”步骤停止，需要修正词表后重试。分享模式只支持按时间段删除。设置或重建时，如果删除记录中含有按片段 ID 记录的条目，会在“片段库”步骤停止并提示条数，不发布新配置；请改为按时间段记录后再重新设置。按时间段记录的删除照常生效。首次设置失败且尚未生成运行配置时，可直接重新运行原命令，无需手动删除中间文件。

重建默认重新生成习惯卡。习惯卡的位置见 `private/dialogue/runtime-config.json` 中的 `habit_card_source`。如果手工换过习惯卡，并且本次仍使用相同的导入和模拟目标，在上面的命令后追加 `--keep-habit-card`，例如 `--rebuild --keep-habit-card`。窗口显示“习惯卡：保留现有（未重新生成）”。找不到现有习惯卡时，设置会在“本机目录”步骤停止并提示去掉 `--keep-habit-card` 重新设置，原有设置不受影响，仍可照常聊天。

iPhone 备份、JSONL（`--format jsonl --chat "文件路径"`）和 Standard JSON v1 数组（`--format standard --chat "文件路径"`）三种输入都支持 `--through-date YYYY-MM-DD`。截止日包含指定时区下当天整天及此前全部消息，次日 00:00:00 起的消息排除；先按消息日期筛选，再执行现有配对规则建库，不会把截止日前的话题配上截止日后的被模仿者回复。`--timezone` 默认 `Asia/Shanghai`；省略 `--through-date` 时，默认日期取本次参数解析时指定时区的当天，不读取操作系统时区。例如可在设置或重建命令后追加 `--through-date 2026-07-17 --timezone America/New_York`。

终端和脚本仍可显式传 `--format`、`--chat`。要在指定文件的同时进入选角色和首次出题流程，在参数后加 `--guided`。

从 iPhone 备份或 JSONL 设置时，会先为全部消息按秒重新编号，保留每一条消息。同一秒内的先后顺序以输入 JSONL 的行序为准，不读取 `local_id` 字段：iPhone 导出文件已按消息时间和本地自增 ID（MesLocalID）排序，直接 JSONL 则使用文件原有行序。预处理将 `server_id` 改为 `timestamp * 1000 + k`，其中 `k` 是同一秒内从 0 开始的行序位置；同一秒超过 1000 条时设置失败，不显示聊天内容。窗口显示“同秒含图片等消息的时刻：N 处（已按原顺序保留）”，只报告含多条消息且有非文字消息的秒数。随后按保留下来的媒体边界筛选回复样本；“文字 → 图片 → 依赖图片的回复”不会进入片段库，同秒纯文字配对仍按原顺序保留。原始输入文件不变，预处理结果保存在本机数据目录的 `private/share/prepared.jsonl`；失败后重试会重新生成。`--format standard` 不经过这次 JSONL 预处理，也不重新编号消息；先校验完整原始输入，再按截止日期筛选，然后建库。每条消息的 `timestamp` 必须是带时区的 ISO 8601 字符串；缺失、空值、数字、无时区或其他非法时间都会使整次设置在“聊天转换”步骤失败，即使该消息原本会被日期筛选排除。原始 standard 输入保持不变；每次设置或重建都会重新生成本机 `private/share/filtered-standard.json`，仅写入保留消息（包括非文字标记），POSIX 文件权限为 `0600`。筛选结果为空也会在“聊天转换”步骤停止，不询问或保存 API key，不生成运行配置。日期筛选只约束建库输入，不表示磁盘上的原始导出或 JSONL 预处理文件已经按日期裁剪。

### 如何删除全部数据

先退出聊天，然后删除本工具的数据文件夹：

- Mac：在 Finder 的“前往”→“前往文件夹”中输入 `~/Library/Application Support/kiki-share`，删除整个 `kiki-share` 文件夹。
- Windows：在文件资源管理器地址栏输入 `%LOCALAPPDATA%\kiki-share`，删除整个 `kiki-share` 文件夹。

再在 Mac“钥匙串访问”中查找并删除服务名为 `kiki-companion` 的条目；Windows 在“凭据管理器”的“Windows 凭据”中删除名称为 `kiki-companion` 的条目，以及所有名称以 `@kiki-companion` 结尾的条目（更换过服务地址时可能有多条）。若要清理备份，用 Finder、Apple Devices 或 iTunes 管理并删除 iPhone 本地备份；你另存的聊天文件也需自行删除。最后可删除整个项目文件夹（包含 `.venv`）。本机删除不会撤回已发送到云端模型服务的数据。

### 费用

本地导入和生成习惯卡免费。明确开始模型分析、出题，以及聊天时可能产生云端模型费用；程序的默认月上限是 **100 元**，按偏高单价估算（每百万输入 token 4 元、输出 token 16 元）。这是程序本地预算估算，不是服务商账单承诺；其他模型的实际价格可能不同，请同时查看服务商余额和用量，并在服务商侧设置费用限制。


### 管理长期记忆

先退出正在运行的聊天，再在终端进入项目目录。首次运行对应系统的命令并输入「同意」确认。它只为当前系统账户授权称呼、偏好和明确备注三个字段。已有的分享资料同意与这项授权相互独立。

Mac 终端命令：

```bash
COMPANION_PRIVATE_DATA_DIR="$HOME/Library/Application Support/kiki-share/private" \
COMPANION_RUNTIME_DATA_DIR="$HOME/Library/Application Support/kiki-share/runtime" \
PYTHONPATH=src .venv/bin/python -m companion.runtime.text_chat --memory grant
```

Windows 命令提示符（cmd）中运行：

```bat
set "COMPANION_PRIVATE_DATA_DIR=%LOCALAPPDATA%\kiki-share\private"
set "COMPANION_RUNTIME_DATA_DIR=%LOCALAPPDATA%\kiki-share\runtime"
set "PYTHONPATH=src"
.venv\Scripts\python.exe -m companion.runtime.text_chat --memory grant
```

将最后的 `grant` 替换为 `list` 查看记忆，替换为 `delete` 按编号选择并确认删除一条，或替换为 `revoke` 确认撤回授权并删除该账户的全部长期记忆。管理命令在本机运行，无需模型 API 密钥。请使用完成分享设置的同一个系统账户。

在正常聊天窗口输入「记住这件事：周末要带拼图」，也可用「记住我喜欢拼图」或「记住以后叫我小雨」。窗口会显示候选事实和四个选项：

- **1 长期记**。按当前账户已授权的字段保存。缺少授权时会给出本地提示，继续选择「仅本次」仍可使用。
- **2 仅本次**。事实只留在当前聊天窗口，可用于该窗口后续问题。输入 `/exit` 或关闭窗口后清除。
- **3 跳过**。留空也可取消。
- **4 自填**。用自己的话改写事实，按明确备注处理，再选长期、本次或跳过。

选项和未确认事实留在本机。只有日后的问题匹配已确认事实时，相关事实才可能随提示发送给已配置的模型服务。普通聊天、导入历史和模型回复不会自动保存为记忆。

检索优先匹配原来的文字子串，也支持部分带明确线索的自然问法。例如保存「周末要带拼图」后，可以问「周末要带什么？」或「周末出门需要带啥？」。近似规则目前针对带上、购买或取回物品的短问句，要求动作一致并有时间或具体物品线索。「要带什么？」缺少这些线索时不会近似召回。支持的问法有限，复杂句可用记忆中已有的词重问。

删除或撤回后，下一轮提示会移除旧记忆及含旧值的近期缓存。Windows 使用当前系统账户的令牌身份，记忆目录与 SQLite 文件的 Windows 权限需通过检查。请用完成分享设置时的普通 Windows 账户运行，保持本地用户目录的原有访问限制。已有共享权限、重解析点或异常硬链接会被拒绝；遇到「本地记忆管理暂不可用」时保留原数据，先检查目录与权限。

#### Windows 复验

在 Windows 普通账户下，用合成配置与资料执行：

```bat
set "PYTHONPATH=src"
.venv\Scripts\python.exe -m pytest -q tests/runtime/test_windows_memory_storage.py tests/integration/test_text_chat_chain.py
```

原生测试应能创建并核验记忆目录、主库以及 SQLite 的 journal、WAL、SHM，并拒绝过宽的访问权限和硬链接。重解析点用例需要允许创建符号链接的系统设置。集成测试使用假模型验证当前账户授权后保存和召回、删除和撤权后的下一轮失效，以及其他账户拒绝访问。当前实现尚待 Windows 真机复验。

## 在聊天中校准风格和记忆

用本页的正常启动方式打开聊天，在提示符输入 `/calibrate-web`。在本机浏览器打开终端显示的临时地址。选择「开始出题」，再逐题确认。校准结束时点击「结束并返回聊天」。关闭标签页时浏览器会尝试结束本轮，终端等待期间也可按 Ctrl+C 返回聊天。

网页只在当前聊天会话中监听本机回环地址，地址仅本轮有效。浏览器页面与聊天会共用本次会话的临时事实，退出聊天后清除。于终端填写可使用 `/calibrate`。也可以从项目目录直接启动分享文本入口，再输入任一命令。

```bash
env PYTHONPATH=src .venv/bin/python -m companion.runtime.text_chat
```

```powershell
$env:PYTHONPATH = "src"
```

程序读本机当前片段库，先排除已删除的片段，再各挑最多一个可供判断的片段。它根据短回复、追问问号、带玩笑提示的引号词、带时间的具体安排来筛选。找不到候选会直接返回聊天。

网页点击「开始出题」或终端输入「出题」才会向已配置的模型发一次请求，可能计费，并计入聊天用量。发送内容只有候选种类和长度分类。片段原文、具体梗、事实和聊天 ID 都在本机处理。出题失败或格式无效时直接返回聊天。

每道风格题可选模型给出的回答，也可自填、标记不确定或跳过。终端对应按键为 `f`、`?` 和 `s`。梗题先问含义，再问「仅用于理解」或「可以接」。风格确认前会显示适用场景、问题和已选回答，保存后只供类似情形参考。点击「确认保存」或在终端输入「确认」后，风格答案保存到本机 `private/dialogue/calibration/` 下当前目标的增量文件，并与基础习惯卡一起用于后续正常聊天。梗的含义只在聊天命中该词时进入提示，用法按所选边界处理。

事实题继续沿用上面的长期记、仅本次、跳过和自填选项。请确认历史安排是否仍然有效，也可以先自填更正。缺少长期授权时，页面或终端会说明当前账户的「明确备注」字段及出站范围，可同意并保存本题，也可取消并选择仅本次。新保存的校准长期事实只用于当前模拟目标；普通聊天中手工记的事实仍按账户使用。旧版已保存且没有来源标记的记忆继续按账户管理，可按上文查看、删除或撤权。匹配的已确认事实、风格偏好和梗义可能随正常聊天提示发送给已配置的模型服务。

### 双回复盲评

Mac 双击「开始聊天.command」，Windows 双击「开始聊天.bat」。在聊天窗口输入 `/blind`，看完费用提示后输入「同意」。沿用同一模型和月度额度，每个比较轮最多请求三次。普通聊天可直接输入消息，记忆和校准命令仍单独处理。

每题会显示「回复 A」和「回复 B」，两条路线的显示顺序独立随机。可输入 `A`、`B`、「差不多」、「两条都不好」、「跳过」或「退出」。选 A 或 B 时只用该条回复继续上下文，其余继续聊天的选项统一沿用 A。生成不完整的轮次不会显示为有效配对。分层路线先从现有当轮和近期上下文选择回应目的 F 和策略 S，再用和原版相同的材料生成措辞 W。

输入 `/feedback` 可保存本窗口的匿名汇总并继续普通聊天。输入 `/exit` 或在投票处选择「退出」也会保存。同一窗口只有一个批次，重复保存使用同一路径。请按终端显示的位置找到 `feedback-*.json`，只把这个文件交给主人。文件包含批次号、总轮数、可比轮数、原版和分层的胜票、A/B 位置投票计数，以及差不多、两条都不好、跳过和失败的计数。胜票分母为明确选择 A 或 B 的次数。差不多、两条都不好、跳过和失败均不计入胜率。

导出包含路线胜票的总数，投票前不显示路线对应，导出也不包含逐轮顺序、回复或用户资料。只有一票等极小批次有可能从总数推断单轮结果，建议比较多轮。
